# Phase 1 Implementation Decisions

- The supplied PDFs are the visual source of truth whenever they conflict with the Master Specification.
- Projects listing will follow the stacked full-width image-band layout from `Projects.pdf`, not the grid described in the older specification.
- Project Detail will not invent an image gallery absent from `Project Details.pdf`.
- Contact footer and quote composition will follow `Contact.pdf`.
- Initial design tokens use PDF-derived values: background `#dbe3e9` and primary navy `#0c2e49` / `#0b2d48`.
- Supplied logo and image assets are preferred over guessed replacements.
- Branding text, nav labels, copyright year, and spelling inconsistencies are preserved for later page-specific resolution.
